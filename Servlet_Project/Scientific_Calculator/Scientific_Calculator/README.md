
# Scientific Calculator Web Application

## Project Information

- Project Name: Scientific Calculator
- Language: Java
- Framework: Java Servlet
- Frontend: HTML, CSS, JavaScript
- Database: MySQL
- JDBC: MySQL Connector
- Server: Apache Tomcat 10.1
- IDE: IntelliJ IDEA

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Power
- Square Root
- Sine
- Cosine
- Tangent
- Logarithm
- Natural Logarithm
- Calculation History
- MySQL Database Integration

## Installation

1. Install JDK.
2. Install IntelliJ IDEA.
3. Install Apache Tomcat 10.1.
4. Install MySQL.
5. Create the database using database.sql.
6. Configure the MySQL password.
7. Reload Maven dependencies.
8. Deploy the project using Tomcat.

## Database

Database Name: scientific_calculator

Table Name: calculation_history

## Run

Open the application:

http://localhost:8080/Scientific_Calculator/
