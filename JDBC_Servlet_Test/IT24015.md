# JDBC Test 1: Insert Nth Prime into Database

## Experiment Objective
To write a Java JDBC program that takes an integer `n` from the keyboard, calculates the nth prime number, and inserts the result into a MySQL database.

## Technologies Used
- Java (JDK 25)
- MySQL
- JDBC
- MySQL Connector/J 9.5.0
- IntelliJ IDEA
- Maven

## Database Setup

Create the database and table using the following SQL commands:

```sql
CREATE DATABASE IF NOT EXISTS prime_db;

USE prime_db;

CREATE TABLE IF NOT EXISTS prime_numbers (
    id INT AUTO_INCREMENT PRIMARY KEY,
    n INT NOT NULL,
    prime_number INT NOT NULL
);
```

## Java Code

**File Name:** `PrimeJDBCTest.java`

```java
import java.sql.*;
import java.util.Scanner;

public class PrimeJDBCTest {

    public static boolean isPrime(int num) {
        if (num < 2) return false;

        for (int i = 2; i <= num / i; i++) {
            if (num % i == 0) return false;
        }
        return true;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter the value of n: ");
        int n = sc.nextInt();

        if (n < 1) {
            System.out.println("Please enter a positive integer.");
            sc.close();
            return;
        }

        int count = 0, num = 1, prime = 0;

        while (count < n) {
            num++;
            if (isPrime(num)) {
                count++;
                prime = num;
            }
        }

        String url = "jdbc:mysql://localhost:3306/prime_db";
        String user = "root";
        String password = "Alif@12345";

        String sql = "INSERT INTO prime_numbers (n, prime_number) VALUES (?, ?)";

        try {
            Class.forName("com.mysql.cj.jdbc.Driver");

            try (Connection con = DriverManager.getConnection(url, user, password);
                 PreparedStatement ps = con.prepareStatement(sql)) {

                ps.setInt(1, n);
                ps.setInt(2, prime);
                ps.executeUpdate();

                System.out.println("n = " + n);
                System.out.println("Prime number = " + prime);
                System.out.println("Inserted successfully!");
            }
        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            sc.close();
        }
    }
}
```

## Maven Dependency

Add the following dependency inside the `<dependencies>` section of `pom.xml`:

```xml
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <version>9.5.0</version>
</dependency>
```

## Configuration

Update the database credentials in the Java code:

```java
String url = "jdbc:mysql://localhost:3306/prime_db";
String user = "root";
String password = "YOUR_MYSQL_PASSWORD";
```

Replace `YOUR_MYSQL_PASSWORD` with your actual MySQL password.

## Algorithm

1. Read the value of `n` from the keyboard.
2. Check whether each number is prime.
3. Count the prime numbers until the nth prime is found.
4. Connect to the MySQL database using JDBC.
5. Insert `n` and its corresponding prime number into the database.
6. Display the result and a success message.

## Conclusion

The experiment demonstrates how to calculate the nth prime number in Java and store the result in a MySQL database using JDBC and `PreparedStatement`.
