# Java Thread Programming

## Overview

This project demonstrates Java Thread programming through two experiments. It explores static and non-static counters using multiple threads and tests different methods of the Java `Thread` class.

## Experiment 01: Static and Non-static Thread

* Creates 100 threads.
* Compares static and non-static counters.
* Measures counter results over 1, 5, and 15 minutes.
* Finds the second-largest integer from an array.

**Run the program:**

```bash
javac Main.java
java Main
```

**Note:** The complete experiment takes approximately 21 minutes.

## Experiment 02: Thread Class Methods

Demonstrates commonly used Java Thread methods, including:

* `start()` and `run()`
* `sleep()` and `join()`
* `yield()`
* `getName()` and `setName()`
* `getPriority()` and `setPriority()`
* `isAlive()` and `getState()`
* `interrupt()` and `isInterrupted()`
* `currentThread()` and `activeCount()`

**Run the program:**

```bash
javac ThreadMethodsDemo.java
java ThreadMethodsDemo
```

## Requirements

* Java Development Kit (JDK)
* Command Prompt or Terminal

## Purpose

To understand multithreading, shared and instance variables, thread execution, and the commonly used methods of Java's `Thread` class.
